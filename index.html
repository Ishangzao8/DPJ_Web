连接设置

在 OneNET 开发者中心「工具 → API 鉴权」生成，res 为 userid/… 形式。
也可直接粘贴设备级 Token（res 含 products/…/devices/…）—— 该 Token 具备读权限，写入需用户级 Token。

配置保存在本机浏览器（localStorage），不会上传到任何服务器。
本页面为纯静态 HTML，直连 iot-api.heclouds.com，无需后端服务。
